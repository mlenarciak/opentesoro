## Release reporting rule

A navigation item, source file or demo card alone is insufficient evidence of feature completion. The implementing path must calculate or persist its promised result, reject invalid input correctly and pass relevant checks. Synthetic tests do not establish a production bank connection, legal compliance, independent security assurance or complete equivalence with a commercial suite.

The first vertical slice has substantial implemented scope; full feature parity remains a staged product effort. See [roadmap](../roadmap.md), [product research](research.md), [current API research](current-api.md), and [Italian tour-operator workflows](italian-tour-operator.md).
